# sparrow-enclave - Game Design Reasoning

## Game Concept
**Sparrow Enclave** is an interactive particle enclosure game where the player draws polygons with the mouse to trap colorful flocking particles (sparrows). The goal is to fully enclose groups of particles to score points. When all 20 target groups are trapped, the player wins and a new round begins with refreshed particles.

## Design Decisions

### Flocking Particle System
- 80 particles with independent velocities and positions
- Particles wrap around screen edges (toroidal movement)
- Each particle has a unique color from a curated palette
- Smooth deceleration via velocity damping (0.98 factor)

### Enclosure Mechanic
- Player clicks and drags to draw polygon vertices
- Closed shapes (3+ vertices) create enclosure boundaries
- Particles inside a closed polygon are removed from play and count as "trapped"
- The trap counter increments only when ALL remaining particles are enclosed within the existing polygons

### Visual Aesthetic
- Deep dark background (#0a0a0f) contrasts with bright particle colors
- Semi-transparent polygon strokes for depth perception
- Clean typography and layered UI elements
- Fade-in title animation on load

### Controls
- **Mouse**: Click and drag to draw polygon vertices
- **R key**: Reset the game at any time
- Particles are trapped when they're fully enclosed by drawn polygons

## Technical Implementation
- Single-file HTML with inline CSS and JavaScript
- Canvas API for rendering particles and polygons
- Point-in-polygon algorithm using ray casting
- No external dependencies - runs directly in browser
- Responsive: adjusts to window resize, particles recreated

## How to Play
1. Draw polygons by clicking and dragging on the canvas
2. Fully enclose groups of sparrows to trap them
3. Trap all 20 groups to win and advance to next round
4. Press **R** to reset the game anytime
